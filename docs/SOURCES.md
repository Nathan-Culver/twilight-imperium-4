# Sources and scope

The baseline is the **base fourth edition**, not Prophecy of Kings, Thunder’s Edge or Codex replacements.

- [User-provided official base Rules Reference](https://images-cdn.fantasyflightgames.com/filer_public/c2/69/c269b9e2-8d9a-420b-a807-2b164dd54977/ti-k0289_rules_referencecompressed.pdf).
- [Fantasy Flight Games product/support page](https://www.fantasyflightgames.com/product/twilight-imperium-fourth-edition/).
- [Official Learn to Play, 2020 PDF](https://cdn.svc.asmodee.net/production-fantasyflightgames/uploads/2026/08/ti-k0289_learn_to_play_2020_web.pdf). Pages 22–23 supply the preset map tile placements for 3, 4, 5 and 6 players. The axial columns were transcribed from the diagrams and checked for unique tile identifiers and correct home-system counts.
- [AsyncTI4 component reference](https://github.com/AsyncTI4/TI4_map_generator_bot). Numerical planet/unit facts, identifiers, faction setup, technology prerequisites and objective criteria were cross-referenced against its base-source component data. No simulator executable, bot implementation or artwork was copied into this app. The data source includes expansion/Codex entries, so only base component records are used; base Magen and X-89 identifiers are retained. Two duplicate non-base Veto records are excluded from the 80-card action deck. Further face-by-face verification against a physical base set is still needed.
- User-supplied [Official Rules](https://twilight-imperium.fandom.com/wiki/Official_Rules) and [Components](https://twilight-imperium.fandom.com/wiki/Components) wiki links were attempted but unavailable through this session’s web retrieval. They were not treated as verified contents.

The component catalogue covers 17 factions, 51 system tiles, 59 planets, 59 technology names/prerequisites, 20 public and 20 secret objectives, and action-card identifiers. Catalogue presence is **not** a claim that every listed component effect is automated. See STATUS.md.

Original vector planets depict fictional worlds using new procedural shading/landforms. They retain component names and numerical values, but do not reproduce the physical tile/card artwork.
