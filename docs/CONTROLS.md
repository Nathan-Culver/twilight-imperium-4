# Controls

Start at **Begin your campaign**, choose a faction, and keep one secret objective. On your turn use **Go to decision** to find the active choice. The **?** controls explain nearby rules.

- **Galaxy:** tap to inspect; pinch to zoom; drag to pan; double tap for zoom/fit. Mouse wheel and +/− also work. Fit shows the entire board. Full screen expands the map; Close map or Escape returns.
- **Tactical action:** select a destination, open Activate, select units in source-system sections, and load infantry explicitly. After any fighting, assign landings, then build or finish.
- **Strategy cards:** choose cards during strategy; use them in your action-phase turn. Respond to other players’ secondary opportunities even if you have passed.
- **Combat:** declare a retreat if desired, roll, then select your own casualties or sustain damage. Ground combat has no retreat.
- **Archive:** download/import saves, create/load checkpoints and review rules/coverage. Downloaded files move between devices; autosaves are tied to the browser.
- **Council:** the first release requires assisted adjudication for agenda outcomes; recording a note does not enforce an agenda effect. See STATUS.md.

The game requires a modern browser supporting ES modules, Pointer Events, dialog and local storage. A downloaded save is recommended before clearing browser data. Once loaded successfully, the service worker caches application modules for offline use. The optional web font falls back to system fonts offline.
